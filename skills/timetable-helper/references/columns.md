# Timetable CSV Columns

| Name | Meaning | Example value |
|---|---|---|
| `batch` | The student cohort assigned to the class. | `CSE-A` |
| `day` | The day of the week when the class meets. | `Monday` |
| `start_time` | The scheduled local start time, in 24-hour `HH:MM` format. | `09:00` |
| `end_time` | The scheduled local end time, in 24-hour `HH:MM` format. | `10:00` |
| `subject` | The name of the class subject. | `Data Structures` |
| `room` | The room assigned to the class. | `CS-101` |
| `faculty` | The faculty member assigned to teach the class. | `Dr. Meera Rao` |
